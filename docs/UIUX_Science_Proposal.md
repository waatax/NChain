# NChain: "Science Behind the App" UX/UI Proposal

## Objective
To design a modern, mobile-first, and engaging user interface that educates users on the cognitive psychology and neuroscience principles underlying the NChain "Number Chain Mnemonic Method." The goal is to build trust and demonstrate the scientific validity of the app's learning mechanics.

## Design Philosophy & Aesthetics
- **Framework & Style**: Vue 3 with Tailwind CSS.
- **Visual Language**: Clean, modern, and minimalist. Utilizing a white/light gray background with soft, diffuse drop shadows to create depth.
- **Color Palette**: 
  - Primary accents: Vibrant purple and deep blue (representing neural pathways and cognitive depth).
  - Secondary accents: Teal and green for progress and positive reinforcement.
- **Typography**: Clean sans-serif fonts (e.g., Inter or Roboto) with strong hierarchical contrast (bold section headers, readable body text).
- **Layout**: Mobile-first, card-based layout to make complex scientific information digestible (Chunking).

## Proposed UI Components

### 1. Educational Modal ("Science Behind the App")
- **Trigger**: A prominent but unobtrusive button (e.g., an info icon or "Learn How It Works" button) on the user's dashboard or profile page.
- **Content**: 
  - A stylized, glowing brain illustration to visually anchor the "Neuroscience of Memory" theme.
  - Sections explaining "The Hippocampus" and "Synaptic Plasticity (LTP)" using simple, user-friendly language.
  - Icons alongside text to reinforce the "Dual Coding Theory" (combining visual and verbal info).
- **Interaction**: A smooth slide-up modal or centered pop-up with a clear 'X' to close, keeping the user in their current flow.

### 2. Scrollable Article / Dashboard Widget
- **Format**: A dedicated scrollable view or a large widget for deeper reading.
- **Features**:
  - **Progress Bar**: At the top, indicating reading progress to encourage completion.
  - **Cognitive Psychology Section**: Cards explaining concepts like "Dual Coding Theory" with custom iconography.
  - **Interactive Chart**: A visual representation of the "Ebbinghaus Forgetting Curve" showing how Spaced Repetition flattens the curve. This makes the abstract concept of memory decay tangible.
  - **Call to Action**: A "View Review Schedule" button to bridge the scientific theory directly to the user's practical usage of the app.

## Rationale
By presenting complex scientific concepts (Hippocampus, LTP, Dual Coding, Chunking, Spaced Repetition) in a highly visual, card-based format, we reduce cognitive load. The UI itself employs the very principles it teaches—using dual coding (text + rich imagery) and chunking (card UI) to help users remember why NChain is effective.
